# Necookie AI — Brand

Necookie AI is an intelligent thinking partner for writing, development, and engineering. The brand should feel clear, capable, and composed. Give the user's work the most visual attention.

## Black and white

Use near-black `#171717`, white `#ffffff`, and neutral grays. Dark mode uses `#111111` with light text and white primary actions. Keep the default interface free of cream, coral, teal, blue-tinted surfaces, and decorative gradients.

Contrast defines hierarchy: a solid primary action, a bordered secondary action, quiet metadata, and generous space. Status messages pair an icon with explicit language. User content, code syntax, and an optional personal message-marker color are exceptions to the neutral interface palette.

## Mark and wordmark

The compact mark is a white N inside a near-black rounded square, implemented in `public/favicon.svg`. Keep it crisp, upright, and unobstructed. Use the same mark in authentication and assistant headers. Keep at least half the mark's width clear around it when space allows.

Write the name as **Necookie AI**. Set the wordmark in Inter at weight 600 with slightly tight spacing. Preserve the mark's proportions and monochrome treatment.

## Type and voice

Use Inter for the product and JetBrains Mono for technical details. Headings are concise and use sentence case. Body text is plain, useful, and direct. Explain the next action or result; avoid inflated claims and unnecessary enthusiasm.

Examples: “New chat”, “Choose a message marker”, “Changes saved”, “Unable to send your message. Try again.”

## Application

Use [DESIGN.md](DESIGN.md) for layouts, tokens, motion, and component behavior. Prefer subtle borders and restrained beUI interactions. Preserve a consistent identity across authentication, chat, folders, settings, help, and responsive layouts.
